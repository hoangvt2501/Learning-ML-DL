Phần a — vì sao np.float16(2049.0) bằng 2048.

FP16 có 10 bit mantissa được lưu, cộng bit ẩn là p=11p = 11p=11 bit độ chính xác (Mục 2.2). Với một số nằm trong [2e, 2e+1)[2^e,\ 2^{e+1})[2e, 2e+1), hai số FP16 liền kề cách nhau

Δ=2 e−10.\Delta = 2^{\,e - 10}. Δ=2e−10.

Số 2049 nằm trong [211,212)=[2048,4096)[2^{11}, 2^{12}) = [2048, 4096)[211,212)=[2048,4096), nên e=11e = 11e=11 và Δ=21=2\Delta = 2^{1} = 2Δ=21=2. Hai số biểu diễn được kề nó là 2048 và 2050, còn 2049 rơi đúng điểm giữa.

IEEE 754 mặc định làm tròn về số gần nhất, hoà thì chọn mantissa chẵn:

  • 2048=1,00000000002×2112048 = 1{,}0000000000_2 \times 2^{11}2048=1,00000000002​×211 — bit cuối mantissa là 0 (chẵn),
  • 2050=1,00000000012×2112050 = 1{,}0000000001_2 \times 2^{11}2050=1,00000000012​×211 — bit cuối mantissa là 1 (lẻ).

Nên kết quả là 2048. Đây cùng một quy tắc đã khiến Z=⌊42,5⌉=42Z = \lfloor 42{,}5 \rceil = 42Z=⌊42,5⌉=42 ở Bài 1, và khiến np.float16(1993.5) = 1994 ở Mục 2.3.

Phần b — số nguyên dương nhỏ nhất không biểu diễn chính xác được.

Một số nguyên nnn biểu diễn được chính xác khi và chỉ khi nó viết được dạng n=m⋅2kn = m \cdot 2^kn=m⋅2k với mmm nguyên và ∣m∣<2p|m| < 2^{p}∣m∣<2p. Nói cách khác: nnn cần không quá p=11p = 11p=11 chữ số có nghĩa trong hệ nhị phân.

  • Mọi n≤2048=211n \le 2048 = 2^{11}n≤2048=211 đều được: 2048=12×2112048 = 1_2 \times 2^{11}2048=12​×211 chỉ cần 1 chữ số có nghĩa.
  • 2049=211+1=10000000000122049 = 2^{11} + 1 = 100000000001_22049=211+1=1000000000012​ cần 12 chữ số có nghĩa, và không rút gọn được vì nó lẻ.

Vậy đáp số là 2049\boxed{2049}2049​, đúng như gợi ý của đề.

def round_ste(x):                       # lượt xuôi: làm tròn; lượt ngược: đồng nhất
    return (x.round() - x).detach() + x

def grad_scale(x, g):                   # lượt xuôi: x; lượt ngược: nhân gradient với g
    return (x - x * g).detach() + x * g

class LsqQuant(nn.Module):
    def __init__(self, n_bits, signed):
        super().__init__()
        self.Qn = 2 ** (n_bits - 1) if signed else 0
        self.Qp = 2 ** (n_bits - 1) - 1 if signed else 2 ** n_bits - 1
        self.S = nn.Parameter(torch.tensor(1.0))
        self.inited = False

    def forward(self, x):
        if not self.inited:             # khởi tạo theo bài báo LSQ
            self.S.data = 2 * x.detach().abs().mean() / (self.Qp ** 0.5)
            self.inited = True
        g = 1.0 / (x.numel() * self.Qp) ** 0.5      # hệ số chỉnh gradient
        s = grad_scale(self.S, g)
        return torch.clamp(round_ste(x / s), -self.Qn, self.Qp) * s
